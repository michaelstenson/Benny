Last updated September 19, 2026

Benny is a private household assistant built for exactly two people — Michael and Mer — to run a shared calendar, chores, bills, and home status. It is not a public product, has no other users, and is not offered or advertised to anyone outside this household.

What Benny accesses, and why

  • Google Calendar — read (and, if enabled, create/edit) events on Michael's and Mer's own calendars, solely to display and manage the shared household calendar inside Benny.
  • Resideo (Honeywell Home) thermostat data — read and control the household thermostat.
  • PowerView smart shade status — read shade position/battery status from a bridge running on the home network.
  • Household data you enter directly — chores, bills, and similar entries typed into Benny.

What Benny does not do

  • Does not access Gmail or any email account.
  • Does not sell, rent, or share this data with advertisers or data brokers.
  • Does not use this data for advertising or third-party analytics.
  • Is not accessible to anyone other than Michael and Mer.

Where data is stored

Household data and connection tokens are stored in a private Supabase database used only by this app. Rows holding credentials (like Google and Resideo tokens) have Row Level Security enabled with no public access policies, so only Benny's own trusted server code can read or write them — not even Benny's own browser-facing key can reach them directly.

Other services Benny talks to

Some features send relevant data to a service that performs that specific feature — for example, a typed sentence like "remind Mer to water the plants Thursday" is sent to Anthropic's Claude API to turn it into a structured chore, and home address/property details are sent to RentCast to look up nearby sale comps. Each of these only receives what that specific feature needs, and only to perform it.

Revoking access

Michael and Mer can each revoke Benny's access to their Google account at any time from their Google Account permissions page.
